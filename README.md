# Apache ZooKeeper: отказоустойчивый координатор расчёта

ДЗ № 4: ансамбль из трёх ZooKeeper 3.9.6 на Java 17, проверка кворума,
эфемерного узла и смены координатора после остановки его процесса.
Расчёт пар навыков перенесён из [ДЗ № 3](https://github.com/MaximKastch/hw3_Data_engineering).

**Отчёт:** [REPORT.md](REPORT.md). В нём результаты экспериментов, ответы
на вопросы и ссылки на исходные журналы.

## Запуск

Нужны Docker с Compose v2 и Python 3.10+. Java и Python-зависимости
устанавливаются внутри образов. Команды выполнять из корня репозитория:

```bash
python scripts/run_all.py
```

Скрипт поднимает три сервера, проверяет ансамбль и эфемерный узел,
запускает два эксперимента с координаторами A и B и сохраняет доказательства.
Каждая пауза лидера длится около 40 секунд; полный прогон занимает несколько минут.
Имена повторных запусков содержат время, поэтому ранее сохранённые журналы
координаторов не перезаписываются. В репозитории приложен прогон `submission`.

Входные данные уже подготовлены: `data/selected_vacancies.csv.gz` содержит
**все 3 894 вакансии**, выбранные исходным фильтром ДЗ № 3.
Это не выборка и не готовые частоты. Координатор заново рассчитывает пары;
эталон из `baseline/` используется только для проверки.
Происхождение и SHA-256 записаны в [data/manifest.json](data/manifest.json).

При наличии исходного ДЗ № 3 проекцию можно подготовить повторно:

```bash
python scripts/prepare_data.py --lab3 ../lab3
```

Снимок результатов уже приложен в `docs/`. Чтобы обновить его после нового
прогона, при установленном Chrome или Edge выполните:

```bash
python scripts/render_report.py
```

Эта команда создаёт HTML, PNG и PDF из фактических журналов; для запуска
самой лабораторной браузер не нужен.

Остановить лабораторный ансамбль, сохранив его данные:

```bash
docker compose down
```

## Что находится в репозитории

| Путь | Назначение |
|---|---|
| `compose.yaml`, `Dockerfile` | Три сервера ZooKeeper и образ координатора |
| `src/coordinator.py` | Выбор лидера, эпоха, чекпоинты и восстановление |
| `src/receiver.py` | Атомарная проверка эпохи при публикации |
| `src/calculation.py` | Исходные правила отбора и подсчёта пар |
| `baseline/`, `data/` | Эталон ДЗ № 3 и полный вход выбранного варианта |
| `logs/` | JSONL-журналы обоих координаторов в обоих режимах |
| `evidence/` | Команды, выводы, состояния ZooKeeper и замеры |
| `results/` | Пересчитанные CSV и проверка совпадения с ДЗ № 3 |
| `REPORT.md`, `docs/` | Отчёт и изображение результатов |

ZooKeeper доступен только на localhost: `2181`, `2182`, `2183`.
У серверов отдельные тома данных и журналов. Все контейнеры находятся
на одном компьютере: проверяется отказ процесса, а не потеря физической машины.
