# Эталон из ДЗ № 3

Файлы скопированы из локальной работы `lab3`, соответствующей репозиторию
[hw3_Data_engineering](https://github.com/MaximKastch/hw3_Data_engineering),
коммит `3a0101b690b04ac8bf5962b674afb178de91a401`.

- `config.json` — исходный вариант и параметры отбора.
- `dataset_manifest.json` — исходные размер, SHA-256 и число строк CSV.
- `metrics.json` — метрики запуска `mr_combined_1`.
- `counts_2.csv` — полный эталон частот пар навыков.

Поле `counts_digest` исходного `metrics.json` относится одновременно к одиночным
навыкам, парам и тройкам. В ДЗ № 4 сравнивается SHA-256 самого `counts_2.csv` и его
байтовое содержимое; это другой вид контрольной суммы.

`scripts/prepare_data.py` читает полный исходный CSV, применяет исходный фильтр и
оставляет все 3894 подходящие вакансии с полями `name`, `role`, `key_skills`.
Пустые навыки и исходный порядок строк сохраняются. Проекция — полный вход
для данного расчёта, а не выборка. Её происхождение, контрольные суммы и проверка
побайтового совпадения пересчитанных пар сохранены в `data/manifest.json`.

В экспериментах пары каждый раз вычисляются заново из проекции. Эталон нужен
только для проверки результата и не используется при восстановлении чекпоинта.
